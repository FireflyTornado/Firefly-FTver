这是这里的第一篇文章。

真正决定要敲下这些文字的时候，我反而不知道该从哪里说起。

关于“写日记”，或者说，“写博客”这件事，我其实想过很多次。偶尔遇到值得记录的事情，会想着“以后一定要把它写下来”；折腾完某个项目，也会觉得其中踩过的坑、做过的尝试，如果只是随着时间慢慢忘掉，好像有些可惜。还有一些更零碎的东西——某个突然冒出来的想法，一段很喜欢的文字，一张照片，一次旅行，甚至只是某一天晚上莫名其妙产生的情绪——它们似乎都值得拥有一个地方，被好好保存下来。

但“以后再写”这句话，说着说着，就过去了很久，直到这件事本身也被忘却。

直到最近，我偶然间找到了 Firefly 的博客模板，十分喜爱。于是我认为，也许真的可以开始了。

# 我最初认识的“网站”

如果认真回想，我对“网站”这件事最早的印象，其实可以追溯到小学的信息课。

那时候的课本里教过我们怎样搭建一个 FTP 服务器。

现在回头看，那其实离今天意义上的“做一个网站”还有很远的距离。没有精心设计的页面，也谈不上什么内容系统，只是按照课本上的步骤一点一点配置，然后尝试让另一台电脑访问自己共享出来的文件。

可对当时的我来说，这件事却很神奇。

原来电脑里的东西并不一定只能待在自己的硬盘里。

只要经过一些设置，它们就可以通过网络，被另一台电脑找到、打开和下载。

那时的我或许还说不清什么是服务器，也不了解域名、前端、后端，更不会去想一个网站究竟是怎样运行起来的。但我第一次很直观地感受到：

**原来我也可以在网络上拥有一个属于自己的地方。**

# 网上冲浪

后来真正接触到互联网上各种各样的网站，这种印象也慢慢发生了变化。

我开始意识到，“网站”并不只是一个用来放文件的地址。

它可以是一家公司面向所有人的门面，可以是一套复杂的服务，也可以只是某个人留在互联网角落里的一间小屋。

有人在这里写技术文章，有人记录旅行，有人整理作品，也有人只是偶尔写下几句近况。

相比那些庞大而复杂的平台，我反而越来越喜欢后者。

一个人按照自己的喜好搭起来的网站，不一定精致，也不一定有很多访问者，却能从字体、颜色、图片，甚至一句不起眼的文字里，看出属于这个人的独特之处。

也许正是那时候开始，我就对这种“在网络上拥有一个自己的地方”的感觉产生了兴趣。

只是彼时的我还不知道，很多年之后，我真的会坐在电脑前，一点一点把这样一个地方搭起来。

# 最近的一点突发奇想

真正让我最近重新冒出“要不要自己做一个网站”这个念头的，其实是一件挺偶然的事。

前段时间，我参与了一个小工具的前端重构工作。

一开始，我只是把它当成一次普通的 UI 重构。原本的关注点更多还是放在“这个按钮应该放在哪里”“这一块界面应该怎么整理”“怎样让用户看起来更赏心悦目”这些很具体的问题上。

但做着做着，我开始频繁接触 CSS 和 JavaScript。

也就是在这个过程中，我突然发现，这两样原本在我印象里多少有些陌生的东西，其实比我想象中有趣得多。

CSS 并不只是给页面“加个颜色”或者“改改字体”。

一个元素放在哪里，间距留多少，页面该怎样随着屏幕大小变化，甚至一段文字在什么位置出现得最舒服，这些看起来很细小的事情，最后都会影响一个界面给人的感觉。

而 JavaScript 又像是给这些静态的界面加上了某种“反应”。

按钮可以回应点击，内容可以随着操作变化，页面上的东西不再只是安静地摆在那里，而是开始和使用它的人产生互动。

这种感觉对我来说有点新鲜。

也是从那个时候开始，我第一次不只是把网页当成一个“打开之后用完就关掉”的东西，而是开始留意它到底是怎么被做出来的。

有时候看到一个喜欢的页面，我会下意识想一想：

这个布局是怎么实现的？

这里为什么会有这样的动画？

如果换成我来做，我会不会把这个地方改成另一种样子？

这些想法一旦冒出来，就有点停不下来了。

然后某一天，我突然想到：

**既然已经开始对这些东西感兴趣了，那为什么不干脆给自己做一个网站呢？**

这个念头并没有经过什么很严肃的规划。

它更像是一种突发奇想。

但奇怪的是，很多真正开始做的事情，好像本来也不是从什么宏大的计划开始的。

只是某一天觉得“好像可以试试”，然后就真的动手了。

于是，曾经停留在小学信息课本里的那个模糊印象，和最近重新燃起的一点兴趣，意外地在这里接上了。

# 为什么想写一个博客

最开始，我并没有给这个博客赋予什么宏大的意义。

它不一定要有多少人阅读，也不一定非要持续输出多么专业、深刻的内容。相比于这些，我更希望这里首先是属于我自己的一个小角落。

互联网的节奏总是很快。

信息不断出现，又不断被新的信息覆盖。短暂的想法被塞进聊天记录，照片沉进越来越长的相册，曾经花费许多时间解决的问题，在几个月后重新遇见时，甚至连自己都记不清当初是怎么处理的。

而博客似乎慢一些。

我可以花时间整理一件事情的前因后果，也可以只是安静地写下一段没有明确目的的文字。它不需要立刻得到回应，也不用被压缩成几句话。

我很喜欢这种感觉。

所以，我想把一些东西留下来。

# 我想在这里写些什么

现在其实还没有一个特别明确的答案。

大概会有一些关于技术的内容。

比如我正在折腾的网站，写代码时遇到的问题，Git 的使用记录，一些突然想到的小功能，以及那些从“应该很简单吧”开始，最后折腾了大半天才终于解决的问题。

也会有一些与技术无关的东西。

旅行时看到的风景，拍下来的照片，喜欢的作品，偶然产生的想法，还有一些关于生活本身的记录。

或许以后回过头来看，会发现这些文章并没有什么统一的主题。

但我觉得这也没什么不好。

因为生活本身好像也从来没有什么“统一的主题”。

今天可能在研究一段代码，明天可能突然想写一场雨，过几天又开始整理一次旅行。博客只是把这些原本散落在不同地方的碎片，慢慢收集到一起。

如果时间足够久，也许它最终会变成某种属于我的时间线。

# “第一篇”为什么这么写？

在创建博客的时候，我其实也想过：

第一篇文章是不是应该特别一点？

是不是应该认真介绍一下自己，讲讲网站为什么叫这个名字，再郑重其事地写一段类似“从今天开始，我要坚持写博客”的宣言？

后来想想，好像没有这个必要。

第一篇文章最重要的事情，或许仅仅只是——

**它真的被写出来了。**

至于这个博客以后会变成什么样，现在的我其实也不知道。

也许文章会越来越多，也许会不断修改网站的样式，也许某一天回头看现在的设计，会觉得处处都是问题。

甚至连这篇文章本身，几年之后再读，大概也会觉得有些青涩。

不过这恰恰也是记录的意义。

如果所有东西都等到“足够成熟”之后才开始，那么很多属于当下的东西，反而永远不会留下来。

所以，就从这里开始吧。

# 写给以后

我很好奇几年后的自己重新看到这里时，会是什么感觉。

那时候这个网站还在吗？

页面会变成什么样？

现在正在做的事情，有多少坚持了下来？

曾经觉得很重要的问题，后来有没有得到答案？

也许未来的我已经忘记了写下这篇文章时的心情。

那也没关系。

至少此刻的我知道，在某个普通的夜晚，我终于给自己一直想做的事情开了一个头。

没有特别隆重的仪式，也没有什么值得纪念的大事件。

只是打开编辑器，写下了一些文字。

于是，这个原本空荡荡的博客里，有了第一篇文章。

而故事，大概也就从这里开始了。
